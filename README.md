# growth-plan-2027

Static landing page: Ukrainian at `/`, English at `/en/`. There is no build step. Edit `index.html`, `en/index.html` and `assets/`, push to `main`, and GitHub Pages republishes.

The pages are marked `noindex`. Font: Onest (SIL OFL 1.1), licence in `assets/fonts/OFL-Onest.txt`.

The neutral, grayscale notes use native HTML details for ideas; they work without JavaScript. Keep the UA/EN content aligned.

Five substantial AI/software projects describe recurring workflows, existing components, new capabilities, delivery stages and measures of value. Hour estimates and the separate context block are omitted.

Expanded projects use a wide layout with process diagrams and an adjustable before/after model. The model counts manual actions in an illustrative 100-action cycle; it does not contain measured project forecasts. Remaining manual actions = unautomated actions + automated actions selected for manual review. All projects start with the same example inputs.
